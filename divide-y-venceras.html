1. ¿Qué es Divide y Vencerás?

Es una estrategia para resolver un problema grande en tres pasos:

1. DIVIDIR

Partir el problema en subproblemas más pequeños del mismo tipo.

2. CONQUISTAR

Resolver cada subproblema. Si todavía es grande, se vuelve a dividir mediante recursión.

3. COMBINAR

Juntar las soluciones para construir la solución del problema original.

Analogía: como una mudanza: dividir por habitaciones, empacar cada habitación y finalmente reunir las cajas.

La idea clave

El problema grande se transforma en problemas pequeños y manejables. Cuando un subproblema llega a un caso base, se resuelve directamente.

PROBLEMA GRANDE ├── DIVIDIR │ ├── Subproblema A │ └── Subproblema B ├── CONQUISTAR │ ├── Resolver A │ └── Resolver B └── COMBINAR └── Solución completa

2. Búsqueda binaria

Es el ejemplo más sencillo de Divide y Vencerás. Trabaja sobre una lista que ya está ordenada.

Paso 1: mirar el elemento del medio.
Paso 2: si es el objetivo, termina.
Paso 3: si el objetivo es menor, continuar solo en la mitad izquierda.
Paso 4: si el objetivo es mayor, continuar solo en la mitad derecha.

Cada paso descarta aproximadamente la mitad de los elementos. Por eso su complejidad es O(log n).

Ejemplo de la clase

Lista: [2, 5, 8, 12, 16, 23, 38, 45, 56, 72]. Buscamos 23.

  1. Medio = 16. Como 23 > 16, descartamos la izquierda.
  2. Medio de [23,38,45,56,72] = 45. Como 23 < 45, vamos a la izquierda.
  3. Medio = 23. Encontrado.

☕ Implementación en Java

public class BusquedaBinaria {
    public static int buscar(int[] arreglo, int objetivo) {
        int inicio = 0;
        int fin = arreglo.length - 1;

        while (inicio <= fin) {
            int medio = (inicio + fin) / 2;

            if (arreglo[medio] == objetivo)
                return medio;
            else if (arreglo[medio] < objetivo)
                inicio = medio + 1;
            else
                fin = medio - 1;
        }

        return -1;
    }

    public static void main(String[] args) {
        int[] arreglo = {2, 5, 8, 12, 16, 23, 38, 45, 56, 72};
        int objetivo = 23;

        int posicion = buscar(arreglo, objetivo);
        System.out.println("Posición: " + posicion);
    }
}

3. Merge Sort — ordenar dividiendo

Merge Sort aplica claramente los tres pasos de Divide y Vencerás.

Dividir

Partir el arreglo por la mitad.

Conquistar

Ordenar cada mitad aplicando Merge Sort nuevamente.

Combinar

Mezclar las dos mitades ordenadas comparando sus elementos uno a uno.

¿Cómo funciona merge?

Si tenemos [3,8] y [1,5]:

1 vs 3 → sale 1; 3 vs 5 → sale 3; 8 vs 5 → sale 5; queda 8.

Resultado: [1,3,5,8].

Trazado de la clase

Arreglo: [8, 3, 5, 1, 9, 2]

[8,3,5,1,9,2] ├── [8,3,5] │ ├── [8] │ └── [3,5] │ ├── [3] │ └── [5] └── [1,9,2] ├── [1] └── [9,2] ├── [9] └── [2] Combinar: [3]+[5] → [3,5] [9]+[2] → [2,9] [8]+[3,5] → [3,5,8] [1]+[2,9] → [1,2,9] [3,5,8]+[1,2,9] → [1,2,3,5,8,9]

Complejidad: O(n log n) en mejor, promedio y peor caso. Usa memoria adicional para realizar la mezcla.

Ejercicio 2 — Trazar Merge Sort

Traza paso a paso [6,2,7,4,1,3], primero dividiendo hasta llegar a elementos individuales y después combinando.

Ver solución

Dividir: [6,2,7] y [4,1,3].

Luego: [6], [2,7] → [2], [7]; y [4], [1,3] → [1], [3].

Combinar: [2]+[7]=[2,7]; [1]+[3]=[1,3].

[6]+[2,7]=[2,6,7]; [4]+[1,3]=[1,3,4].

Final: [1,2,3,4,6,7].

4. Quick Sort — ordenar con un pivote

Quick Sort también utiliza Divide y Vencerás, pero divide de una manera diferente: selecciona un pivote y reorganiza el arreglo alrededor de él.

1. Elegir pivote: en esta clase se usa el último elemento.
2. Particionar: menores a la izquierda y mayores a la derecha.
3. Dejar el pivote en su posición final.
4. Repetir: Quick Sort para la parte izquierda y para la derecha.

A diferencia de Merge Sort, no hay un merge final: cuando las partes quedan ordenadas y cada pivote está en su posición, el arreglo queda ordenado.

Trazado de la clase

Arreglo: [8,3,5,1,9,2]

  1. Pivote 2 → [1,2,5,8,9,3].
  2. Parte derecha [5,8,9,3], pivote 3 → [1,2,3,8,9,5].
  3. Parte derecha [8,9,5], pivote 5 → [1,2,3,5,9,8].
  4. Parte derecha [9,8], pivote 8 → [1,2,3,5,8,9].

Complejidad: O(n log n) en promedio y O(n²) en el peor caso cuando la elección del pivote produce particiones muy desbalanceadas.

Ejercicio 3 — Trazar Quick Sort

Usa pivote = último elemento para ordenar [6,2,7,4,1,3].

Ver solución

Pivote 3 → [2,1,3,4,6,7].

Izquierda [2,1], pivote 1 → [1,2].

Derecha [4,6,7]: las particiones con pivote 7 y después 6 no requieren intercambios adicionales.

Resultado: [1,2,3,4,6,7].

5. Merge Sort vs. Quick Sort

CaracterísticaMerge SortQuick Sort
Cómo divideSiempre por la mitad exacta.Según dónde quede el pivote.
CombinarSí, mediante merge.No existe un merge final.
ComplejidadO(n log n) siempre.O(n log n) promedio; O(n²) peor caso.
MemoriaUsa memoria extra para la mezcla.Ordena sobre el mismo arreglo.
Para recordar: Merge Sort divide parejo y después combina. Quick Sort divide alrededor de un pivote y no necesita combinar al final.

Java 1 — Búsqueda binaria

public class BusquedaBinaria {
    public static void main(String[] args) {
        int[] arreglo = {2, 5, 8, 12, 16, 23, 38, 45, 56, 72};
        int objetivo = 23;

        int inicio = 0;
        int fin = arreglo.length - 1;
        int posicion = -1;

        while (inicio <= fin) {
            int medio = (inicio + fin) / 2;

            if (arreglo[medio] == objetivo) {
                posicion = medio;
                break;
            } else if (arreglo[medio] < objetivo) {
                inicio = medio + 1;
            } else {
                fin = medio - 1;
            }
        }

        System.out.println("Posición: " + posicion);
    }
}

Qué deben identificar: medio, comparación con el objetivo, descarte de una mitad y condición de finalización.

☕ Implementación en Java — Merge Sort

import java.util.Arrays;

public class MergeSort {
    static void mergeSort(int[] a, int inicio, int fin) {
        if (inicio >= fin) return;

        int medio = (inicio + fin) / 2;

        mergeSort(a, inicio, medio);
        mergeSort(a, medio + 1, fin);
        merge(a, inicio, medio, fin);
    }

    static void merge(int[] a, int inicio, int medio, int fin) {
        int[] temp = new int[fin - inicio + 1];
        int i = inicio, j = medio + 1, k = 0;

        while (i <= medio && j <= fin) {
            if (a[i] <= a[j]) temp[k++] = a[i++];
            else temp[k++] = a[j++];
        }

        while (i <= medio) temp[k++] = a[i++];
        while (j <= fin) temp[k++] = a[j++];

        for (int x = 0; x < temp.length; x++)
            a[inicio + x] = temp[x];
    }

    public static void main(String[] args) {
        int[] a = {6, 2, 7, 4, 1, 3};

        System.out.println("Antes: " + Arrays.toString(a));
        mergeSort(a, 0, a.length - 1);
        System.out.println("Después: " + Arrays.toString(a));
    }
}

🐍 Implementación en Python — Merge Sort

def merge_sort(arreglo):
    if len(arreglo) <= 1:
        return arreglo

    medio = len(arreglo) // 2
    izquierda = merge_sort(arreglo[:medio])
    derecha = merge_sort(arreglo[medio:])

    resultado = []
    i = j = 0

    while i < len(izquierda) and j < len(derecha):
        if izquierda[i] <= derecha[j]:
            resultado.append(izquierda[i])
            i += 1
        else:
            resultado.append(derecha[j])
            j += 1

    resultado.extend(izquierda[i:])
    resultado.extend(derecha[j:])
    return resultado


arreglo = [6, 2, 7, 4, 1, 3]
print("Antes:", arreglo)
print("Después:", merge_sort(arreglo))

Qué deben identificar: caso base, llamadas recursivas, división por el medio y función merge.

☕ Implementación en Java — Quick Sort

import java.util.Arrays;

public class QuickSort {
    static void quickSort(int[] a, int inicio, int fin) {
        if (inicio >= fin) return;

        int pivote = particionar(a, inicio, fin);

        quickSort(a, inicio, pivote - 1);
        quickSort(a, pivote + 1, fin);
    }

    static int particionar(int[] a, int inicio, int fin) {
        int pivote = a[fin];
        int i = inicio - 1;

        for (int j = inicio; j < fin; j++) {
            if (a[j] < pivote) {
                i++;
                int temp = a[i];
                a[i] = a[j];
                a[j] = temp;
            }
        }

        int temp = a[i + 1];
        a[i + 1] = a[fin];
        a[fin] = temp;

        return i + 1;
    }

    public static void main(String[] args) {
        int[] a = {6, 2, 7, 4, 1, 3};

        System.out.println("Antes: " + Arrays.toString(a));
        quickSort(a, 0, a.length - 1);
        System.out.println("Después: " + Arrays.toString(a));
    }
}

🐍 Implementación en Python — Quick Sort

def particionar(arreglo, inicio, fin):
    pivote = arreglo[fin]
    i = inicio - 1

    for j in range(inicio, fin):
        if arreglo[j] < pivote:
            i += 1
            arreglo[i], arreglo[j] = arreglo[j], arreglo[i]

    arreglo[i + 1], arreglo[fin] = arreglo[fin], arreglo[i + 1]
    return i + 1


def quick_sort(arreglo, inicio, fin):
    if inicio >= fin:
        return

    posicion = particionar(arreglo, inicio, fin)
    quick_sort(arreglo, inicio, posicion - 1)
    quick_sort(arreglo, posicion + 1, fin)


arreglo = [6, 2, 7, 4, 1, 3]
print("Antes:", arreglo)
quick_sort(arreglo, 0, len(arreglo) - 1)
print("Después:", arreglo)

Qué deben identificar: pivote, partición, posición final del pivote y dos llamadas recursivas.
