1. 🟢 ¿Qué es un algoritmo voraz?

Un algoritmo voraz construye una solución tomando, en cada paso, la opción que parece mejor en ese momento, sin regresar a cambiar decisiones anteriores.

Decisión local

¿Cuál es la mejor opción que puedo tomar ahora?

Sin retroceder

Una vez tomada la decisión, normalmente no se deshace.

Meta global

Esperamos que esas decisiones locales construyan una solución óptima.

¡Ojo! “Elegir lo más grande/pequeño” no garantiza automáticamente una solución óptima. Hay que justificar que la estrategia funciona para ese problema.

🔑 Los 3 conceptos que debes poder explicar

1. Propiedad de elección voraz

Podemos tomar la elección local correcta y todavía llegar a una solución óptima global.

Pregunta: “¿Puedo comprometerme con esta decisión desde ahora?”

2. Subestructura óptima

Después de tomar una decisión, lo que queda puede resolverse como un subproblema cuya solución óptima ayuda a construir la solución completa.

Pregunta: “¿Lo que queda sigue siendo un problema del mismo tipo?”

3. Argumento de intercambio

Demostramos que si una solución óptima tomó otra decisión, podemos reemplazarla por la decisión voraz sin empeorar la solución.

Pregunta: “¿Puedo cambiar la primera decisión por la voraz y seguir teniendo una solución óptima?”

🪙 Ejemplo donde Greedy falla

Queremos devolver $6 usando monedas {1, 3, 4}, buscando el menor número de monedas.

Greedy

4 → queda 2 → 1 → queda 1 → 1

3 monedas: 4+1+1

Óptimo

3 → queda 3 → 0

2 monedas: 3+3

Conclusión: no podemos decir “Greedy siempre funciona”. Primero debemos estudiar si el problema tiene las propiedades necesarias.

🧠 Mini comprobación

Si un algoritmo siempre toma la opción local más barata, ¿eso por sí solo demuestra que encontró la solución óptima?

2. 📅 Selección de actividades

Problema: tenemos actividades con hora de inicio y fin. Queremos escoger el mayor número posible sin que se solapen.

ActividadInicioFin
A114
A235
A306
A457

Regla voraz: ordenar por hora de finalización y escoger siempre la siguiente actividad compatible.

▶️ Simulación paso a paso

1
Elegir A1
2
Buscar después de 4
3
Elegir A4
4
Elegir A6
A1 termina en 4. Ahora solo podemos elegir una actividad cuyo inicio sea ≥ 4.
Seleccionadas: A1

💡 ¿Por qué ordenar por hora de fin?

Porque una actividad que termina más temprano deja igual o más espacio para las actividades siguientes.

Argumento de intercambio, en lenguaje sencillo: si una solución óptima comenzó con otra actividad que termina más tarde, podemos reemplazarla por la actividad que termina más temprano. No perdemos espacio para las actividades siguientes. Por eso la elección voraz es segura.

💻 Implementación

actividades = [
    ("A1", 1, 4), ("A2", 3, 5), ("A3", 0, 6),
    ("A4", 5, 7), ("A5", 5, 9), ("A6", 8, 9)
]

# 1. Ordenar por hora de FIN
actividades.sort(key=lambda a: a[2])

seleccionadas = []
fin_actual = -1

# 2. Elegir la siguiente compatible
for nombre, inicio, fin in actividades:
    if inicio >= fin_actual:
        seleccionadas.append(nombre)
        fin_actual = fin

print(seleccionadas)
# ['A1', 'A4', 'A6']
import java.util.*;

public class Actividades {
    public static void main(String[] args) {
        int[][] actividades = {
            {1,4}, {3,5}, {0,6},
            {5,7}, {5,9}, {8,9}
        };

        // Ordenar por hora de FIN
        Arrays.sort(actividades, Comparator.comparingInt(a -> a[1]));

        int finActual = -1;

        for (int[] a : actividades) {
            int inicio = a[0];
            int fin = a[1];

            if (inicio >= finActual) {
                System.out.println("Elegida: " + inicio + "-" + fin);
                finActual = fin;
            }
        }
    }
}

3. 🌐 Árbol de Expansión Mínima (MST)

Un árbol de expansión mínima conecta todos los vértices de un grafo, no tiene ciclos y busca minimizar el peso total de las aristas.

🏙️ Ejemplo: conectar varias ciudades con fibra óptica gastando lo menos posible, sin dejar ninguna ciudad desconectada.

Para n vértices, un árbol tiene exactamente n − 1 aristas.

📌 Grafo de la clase

Aristas: BC=1, AC=2, DE=2, AB=4, BD=5, CD=8, CE=10.

Paso 0: ordenamos las aristas de menor a mayor.

🔵 Kruskal en palabras muy simples

  1. Ordeno todas las aristas de menor a mayor.
  2. Tomo la más barata.
  3. Pregunto: “¿esta arista forma un ciclo?”
  4. Si NO forma ciclo → la agrego.
  5. Si forma ciclo → la descarto.
  6. Paro cuando tengo n − 1 aristas.
Resultado del ejemplo: BC(1), AC(2), DE(2), BD(5). Peso total = 10.

💻 Kruskal: código

aristas = [
    (1, "B", "C"), (2, "A", "C"), (2, "D", "E"),
    (4, "A", "B"), (5, "B", "D"), (8, "C", "D"), (10, "C", "E")
]

aristas.sort()

padre = {v: v for v in "ABCDE"}

def find(x):
    while padre[x] != x:
        x = padre[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb:
        padre[rb] = ra
        return True
    return False

mst = []
for peso, u, v in aristas:
    if union(u, v):
        mst.append((u, v, peso))

print(mst)
import java.util.*;

public class Kruskal {
    static int[] padre;

    static int find(int x) {
        while (padre[x] != x)
            x = padre[x];
        return x;
    }

    static boolean union(int a, int b) {
        int ra = find(a);
        int rb = find(b);

        if (ra == rb) return false;

        padre[rb] = ra;
        return true;
    }

    public static void main(String[] args) {
        // {u, v, peso}
        int[][] aristas = {
            {1, 2, 1}, {0, 2, 2}, {3, 4, 2},
            {0, 1, 4}, {1, 3, 5}, {2, 3, 8}, {2, 4, 10}
        };

        Arrays.sort(aristas, Comparator.comparingInt(a -> a[2]));

        padre = new int[5];
        for (int i = 0; i < 5; i++) padre[i] = i;

        int total = 0;

        for (int[] e : aristas) {
            if (union(e[0], e[1])) {
                System.out.println("Se agrega: " +
                    e[0] + "-" + e[1] + " peso " + e[2]);
                total += e[2];
            }
        }

        System.out.println("Peso total: " + total);
    }
}

4. 🔗 Conjuntos disjuntos (Union-Find)

Esta estructura ayuda a Kruskal a responder una pregunta fundamental:

“¿Estos dos vértices ya están conectados dentro del mismo grupo?”

Trabajamos principalmente con dos operaciones:

find(x)

Busca la raíz o representante del grupo al que pertenece x.

union(x,y)

Une los grupos de x y y.

🧩 Simulación de grupos

Comenzamos:

Cada vértice está solo: {A} {B} {C} {D} {E}

🚨 ¿Cómo detectamos un ciclo?

Para una arista (u,v):

si find(u) == find(v)
    → ya están en el mismo grupo
    → agregar la arista formaría un ciclo
    → DESCARTAR

si find(u) != find(v)
    → están en grupos diferentes
    → podemos unirlos
    → AGREGAR
Esta es la idea: “misma raíz = mismo grupo = ciclo; raíz diferente = grupos diferentes = se puede unir”.

5. 🌱 Prim

Prim busca también un árbol de expansión mínima, pero trabaja de otra manera.

Kruskal

Piensa en todas las aristas ordenadas y va escogiendo las más baratas sin crear ciclos.

Prim

Empieza en un vértice y hace crecer el árbol buscando la arista más barata que conecte el árbol con un vértice nuevo.

▶️ Prim desde A, paso a paso

Comenzamos con el árbol {A}.

💻 Prim: idea en código

import heapq

# (peso, origen, destino)
grafo = {
    "A": [(4,"B"), (2,"C")],
    "B": [(4,"A"), (1,"C"), (5,"D")],
    "C": [(2,"A"), (1,"B"), (8,"D"), (10,"E")],
    "D": [(5,"B"), (8,"C"), (2,"E")],
    "E": [(10,"C"), (2,"D")]
}

visitados = {"A"}
cola = []

for peso, destino in grafo["A"]:
    heapq.heappush(cola, (peso, "A", destino))

mst = []

while cola and len(visitados) < len(grafo):
    peso, u, v = heapq.heappop(cola)

    if v in visitados:
        continue

    visitados.add(v)
    mst.append((u, v, peso))

    for p, w in grafo[v]:
        if w not in visitados:
            heapq.heappush(cola, (p, v, w))

print(mst)
// Idea simplificada de Prim:
// 1. Empiezo con un vértice.
// 2. Busco la arista más barata que salga del árbol.
// 3. Agrego el nuevo vértice.
// 4. Repito hasta incluirlos todos.

boolean[] visitado = new boolean[n];
visitado[0] = true;

for (int paso = 0; paso < n - 1; paso++) {
    int mejorPeso = Integer.MAX_VALUE;
    int u = -1, v = -1;

    for (int i = 0; i < n; i++) {
        if (!visitado[i]) continue;

        for (int j = 0; j < n; j++) {
            if (!visitado[j] && grafo[i][j] < mejorPeso) {
                mejorPeso = grafo[i][j];
                u = i;
                v = j;
            }
        }
    }

    visitado[v] = true;
    System.out.println("Agrego: " + u + " - " + v);
}

7. 🚚 Conexión con el proyecto del semestre

El proyecto de la tienda de barrio plantea para el Corte 2 una heurística voraz del vecino más cercano y luego una variante con restricción de capacidad.

La idea: estando en la tienda, escoger el cliente más cercano disponible; después, desde ese cliente, escoger el siguiente más cercano que se pueda atender, y continuar.

🧭 Ejemplo sencillo

Supongamos que la tienda está en (0,0) y tenemos:

ClienteXYDistancia aproximada
C1212.24
C2515.10
C3122.24
C4657.81

Una estrategia voraz podría comenzar por el cliente más cercano disponible.

Importante: “voraz” significa que tomamos la mejor decisión local; eso no significa automáticamente que la ruta sea la mejor ruta global posible.

💻 Vecino más cercano — versión didáctica

clientes = {
    "C1": (2,1),
    "C2": (5,1),
    "C3": (1,2),
    "C4": (6,5)
}

actual = (0,0)
pendientes = set(clientes)

while pendientes:
    # Buscar el cliente más cercano
    siguiente = min(
        pendientes,
        key=lambda c: distancia(actual, clientes[c])
    )

    print("Voy a:", siguiente)
    actual = clientes[siguiente]
    pendientes.remove(siguiente)
// Idea didáctica de Vecino Más Cercano
// actual = tienda o último cliente visitado

while (!pendientes.isEmpty()) {

    String siguiente = null;
    double menor = Double.MAX_VALUE;

    for (String cliente : pendientes) {
        double d = distancia(actual, coordenadas.get(cliente));

        if (d < menor) {
            menor = d;
            siguiente = cliente;
        }
    }

    System.out.println("Voy a: " + siguiente);
    actual = coordenadas.get(siguiente);
    pendientes.remove(siguiente);
}
