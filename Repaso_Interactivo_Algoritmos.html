🎯 ¿Qué vamos a aprender?

La pregunta central es: ¿cómo cambia el trabajo de un algoritmo cuando aumenta la cantidad de datos?

Notación asintótica
Describe cómo crece el costo de un algoritmo cuando aumenta el tamaño de la entrada.
Big-O
Expresa una cota superior del crecimiento de la complejidad.
Divide y vencerás
Dividir el problema, resolver partes más pequeñas y combinar las soluciones.

💡 Idea clave: no estamos contando segundos exactos de un computador; estamos estudiando cómo crece el trabajo.

📈 1. Notación asintótica y Big-O

Definición: Big-O describe la cota superior del crecimiento del costo de un algoritmo a medida que aumenta la entrada.

O(n)

Un recorrido por n elementos.

para cada elemento
  hacer algo

O(n²)

Dos ciclos anidados de n elementos.

para i = 1 hasta n
  para j = 1 hasta n
    hacer algo

🎚️ Mueve el tamaño de los datos

n = 10
O(n)10 operaciones
O(n²)100 operaciones

🔁 2. Recurrencias

Definición: una recurrencia es una ecuación que describe el costo de un algoritmo recursivo en función del costo de resolver problemas más pequeños.

Una forma general que aparece en la guía es:

T(n) = aT(n/b) + f(n)
T(n)
Tiempo/costo para un problema de tamaño n.
a
Número de subproblemas.
n/b
Tamaño de cada subproblema.
f(n)
Trabajo adicional fuera de las llamadas recursivas.

📚 Ejemplo: Merge Sort

T(n) = 2T(n/2) + O(n)

Hay 2 subproblemas, cada uno de tamaño n/2, y además se hace trabajo lineal para combinar.

Con el Teorema Maestro, esta recurrencia da O(n log n).

🧩 4. Merge Sort

Definición: algoritmo de ordenamiento que usa divide y vencerás: divide el arreglo, ordena las partes y las combina.
Listo

Presiona “Ver paso”.

Complejidad: O(n log n).

⚡ 5. Quick Sort

Definición: algoritmo de ordenamiento que usa divide y vencerás y selecciona un elemento llamado pivote para particionar el arreglo.

En el examen se pide usar el último elemento como pivote.

Pista: primero identifica el pivote.

Promedio: O(n log n)
Peor caso: O(n²), por ejemplo cuando las particiones quedan muy desbalanceadas.

🔎 6. Búsqueda lineal vs. binaria

🚶 Búsqueda lineal

Definición: revisa los elementos uno por uno hasta encontrar el buscado o terminar la lista.
O(n)

✂️ Búsqueda binaria

Definición: reduce aproximadamente a la mitad el espacio de búsqueda en cada paso.
O(log n)

🚨 Condición indispensable: la lista debe estar ordenada.
